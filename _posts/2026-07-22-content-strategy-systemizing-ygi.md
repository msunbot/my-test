## The epiphany

The content game isn't "post good stuff and hope." It's a system with two distinct outputs, a follower threshold that unlocks compounding, and an operator (Ygi) who needs clear, repeatable jobs rather than vague "help with content."

**The model:**
- **1 viral hit piece / week** on Twitter + LinkedIn — built to build audience, not to teach.
- **1 in-depth piece / week** — the research/thinking piece, the thing that makes the hit piece's new followers stick around.
- **Substack** is the long-term home. Twitter/LinkedIn growth and Notes are the discovery engine that feeds it.
- **Follower thresholds**: 50k on Twitter, 20k on LinkedIn — the point at which I'm credibly "an influencer," which lowers friction for Substack growth (collabs, cross-promotion, being taken seriously).

The rest of this post is the system for getting Ygi to actually run this, week over week, without me re-explaining it every time.

## The four jobs for Ygi

Everything I mentioned collapses into four repeatable workflows. Each needs an SOP, a cadence, and a clear definition of "done" — otherwise "help with content" stays a vague ask instead of a job.

### 1. Weekly content production (editing + distribution)

**Cadence:** every week, 1 hit piece + 1 in-depth piece.

| Step | Owner | Output |
|---|---|---|
| Draft hit piece + in-depth piece | Me | Raw draft (doc or voice note transcript) |
| Edit for platform (hook, formatting, length) | Ygi | Twitter thread version, LinkedIn version, Substack version |
| Schedule/post across Twitter, LinkedIn, Substack | Ygi | Live posts + a tracking row (link, date, platform) |
| Log performance 48h later | Ygi | Views/likes/comments/follower delta in a shared tracker |

Give Ygi a **style guide** (voice, banned words, hook formulas, formatting rules per platform) once, so editing doesn't require me reviewing every post before it goes out. Start with "draft → I approve → post" for 2-3 weeks, then graduate to "draft → post" once the style guide is proven out, with a same-day flag-for-review only if something's ambiguous.

### 2. Substack Notes engagement (discovery via commenting)

This is the one you flagged as chronically under-done — so it needs to be the most systemized, not the most aspirational.

**The system:**
1. **Build a target list** — 30-50 Substack accounts in/adjacent to robotics, AI, deep tech. Ygi maintains this as a living list, adding accounts we discover.
2. **Daily sweep** — Ygi checks Notes from that list + the general feed for posts worth engaging with (10-15 min/day, not a research project).
3. **Comment quotas, not vibes** — a concrete daily number (e.g., 5 substantive comments/day) is a job Ygi can own and report on. "Substantive" = adds a point, asks a real question, or shares a relevant data point — not "great post!"
4. **Weekly report** — which comments got replies/likes, which accounts are worth following more closely, any DMs or connections that opened up.

Optional escalation once this is running smoothly: Ygi drafts comments for anything that needs my voice/expertise, I approve in under a minute, Ygi posts.

### 3. Brainstorming pipeline (swipe file from other robotics influencers)

**The system:**
1. **Watchlist** — Ygi maintains a list of robotics/AI influencer accounts (Twitter + LinkedIn) to monitor.
2. **Weekly swipe file** — Ygi screenshots/logs viral posts from that list (what made it hit: hook, format, topic, timing), delivered as a short weekly doc, not a live feed I have to babysit.
3. **Pattern-matching, not copying** — the swipe file should extract the *mechanism* (contrarian take, prediction, data-driven hook, personal story) so it becomes raw material for **my** hit piece, not a template to clone.
4. **Feed into content production** — this swipe file becomes an input to Job #1: before drafting the week's hit piece, skim the swipe file for angles.

### 4. Metrics + the influencer threshold

Ygi tracks one dashboard, updated weekly:
- Twitter followers (progress toward 50k)
- LinkedIn followers (progress toward 20k)
- Substack subscribers + Notes engagement
- Which hit piece each week drove the most follower growth (so we can double down on what's working)

## Weekly rhythm (proposed)

| Day | Activity |
|---|---|
| Mon | I send raw draft ideas/voice notes for the week's 2 pieces |
| Tue | Ygi delivers edited drafts for both pieces; I approve/revise |
| Wed | Hit piece goes live (Twitter + LinkedIn); Substack Notes/comment sweep continues daily |
| Thu | In-depth piece goes live on Substack (+ shortened versions on Twitter/LinkedIn) |
| Fri | Ygi delivers: performance recap, swipe file for next week, Notes engagement report |
